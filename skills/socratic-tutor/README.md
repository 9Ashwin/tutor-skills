# 苏格拉底导师技能(Socratic Tutor)

把任意 AI agent 变成高质量导师:将「我想学 X」转化为可验证的能力,用苏格拉底式提问引导,由闭环反馈循环驱动。

## 核心理念

> AI 缩短反馈循环;它不是知识源。能力 = 撤掉 AI 之后你还能做什么。

## 为什么叫苏格拉底

苏格拉底不直接给答案,而是用一连串问题逼对方自己想出来。学习者的每一次尝试,都比 AI 的每一次讲解更值钱。提示阶梯就是这个思想的落地:先引导,后讲解,最后才给完整答案。

## 两层设计

**日常辅导(默认,轻量)**:只守三条铁律——① 尝试先于答案 ② 每次会话至少 1 次主动回忆 ③ 错一次记一个错误类型。不建任何文件,轻才用得起来。

**系统学习(说"系统学 X"/"做套课程"时启用)**:完整闭环,全套机制:
- 基线诊断 → SMART+OKR → 资源栈 → 最小单元 → 主动回忆 → 提示阶梯 → 变式迁移 → 间隔重复 → 无AI验收 → 真实迁移
- 教学工作区:MISSION / map.md / review-queue.md / RESOURCES / NOTES / learning-records / no-ai-test / lessons / reference / assets
- 掌握门槛 gate:无AI ≥90% + 迁移独立完成 + 能解释原理

## 特性

- **监考式无 AI 测验** — 题目答案分离、一题一问当场判分;有AI得分用同难度不同题;分差逐轮缩小 = 学习真实发生
- **间隔重复有排期** — review-queue.md 记录 3-7-14 天,会话开场先清到期项
- **知识地图** — map.md 可视化地形 + 进度状态,喂最近发展区判断
- **提示阶梯组件** — assets/prompt-ladder.html 五级阶梯,每课结尾锚定
- **错误类型映射** — 记完要用:概念缺失→重教、条件遗漏→边界变式、错误类比→反例、计算→专项、策略→专家思路、粗心→检查清单

## 用法

用这些说法触发:

- "教我 X" / "Teach me X"
- "怎么学 Y" / "How do I learn Y?"
- "学习计划" / "Make me a study plan for Z"
- "辅导我 ..." / "Tutor me on ..."

技能自包含:它会创建并维护教学工作区、跑闭环循环、用 rubric 批改。

## 文件

- `SKILL.md` — 技能定义与指令
- `test-prompts.json` — 验证用测试 prompt

## 设计说明

- 融合两条成熟传统:闭环学习法(目标 → 基线 → 资源栈 → 最小单元 → 主动回忆 → 反馈 → 间隔 → 迁移)+ 教学工作区模式(MISSION / lessons / reference / learning-records / assets)。
- 语言无关:适用于编程、语言、数学、手艺等任何主题。
- Agent 无关:不绑定任何平台 hook,任何 LLM agent 都能采纳。
