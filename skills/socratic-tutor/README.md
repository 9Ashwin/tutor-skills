# 苏格拉底导师技能(Socratic Tutor)

把任意 AI agent 变成高质量导师:将「我想学 X」转化为可验证的能力,用苏格拉底式提问引导,由闭环反馈循环驱动。

## 核心理念

> AI 缩短反馈循环;它不是知识源。能力 = 撤掉 AI 之后你还能做什么。

## 为什么叫苏格拉底

苏格拉底不直接给答案,而是用一连串问题逼对方自己想出来。学习者的每一次尝试,都比 AI 的每一次讲解更值钱。提示阶梯就是这个思想的落地:先引导,后讲解,最后才给完整答案。

## 特性

- **先做基线诊断** — 用任务测真实起点,不信自我评估;**首会话强制建 `no-ai-test/BASELINE.md` 记 0 周基线分**
- **双层目标** — SMART(具体/可衡量/可达/相关/有时限)+ OKR(结果不是活动),含关键的 有AI vs 无AI 差距指标
- **源头优先资源栈** — 官方文档 → 权威课程 → 高质量综述 → 专家解读 → 社区;原始资料保留原文
- **最小单元课程** — 一课一个紧扣使命的紧凑主题,一个看得见的收获
- **讲解前先主动回忆** — 学习者先回忆,再被讲解
- **提示阶梯反馈(组件化)** — `assets/prompt-ladder.html` 五级阶梯,每课结尾锚定;尝试 → 错误区域 → 引导问题 → 原则 → 局部例子 → 完整解法(仅应求给出)
- **错误分类学(强制字段)** — learning-records 模板带 `error-type:` frontmatter(概念缺失 / 条件遗漏 / 错误类比 / 计算错误 / 策略 / 粗心),不是可选项
- **变式 + 迁移练习** — 同一概念换皮,再跨情境
- **间隔重复 + 无AI延迟测验(记分表)** — FSRS 式间隔;`no-ai-test/BASELINE.md` 记录每轮 无AI/有AI 分差,分差逐轮缩小 = 学习真实发生
- **真实世界迁移收官** — 应用到真实项目或陌生情境
- **有状态教学工作区** — MISSION / RESOURCES / NOTES / learning-records / no-ai-test / lessons / reference / assets

## 用法

用这些说法触发:

- "教我 X" / "Teach me X"
- "怎么学 Y" / "How do I learn Y?"
- "学习计划" / "Make me a study plan for Z"
- "辅导我 ..." / "Tutor me on ..."

技能自包含:它会创建并维护教学工作区、跑闭环循环、用 rubric 批改。

## 文件

- `SKILL.md` — 技能定义与指令
- `test-prompts.json` — 验证用测试 prompt

## 设计说明

- 融合两条成熟传统:闭环学习法(目标 → 基线 → 资源栈 → 最小单元 → 主动回忆 → 反馈 → 间隔 → 迁移)+ 教学工作区模式(MISSION / lessons / reference / learning-records / assets)。
- 语言无关:适用于编程、语言、数学、手艺等任何主题。
- Agent 无关:不绑定任何平台 hook,任何 LLM agent 都能采纳。
