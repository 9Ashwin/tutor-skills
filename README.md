# tutor-skills · 苏格拉底导师

让任意 AI agent 变成**真正会教**的导师:把「我想学 X」转化为可验证的能力,而不是"听起来懂了"。

```
尝试先于答案 → 主动回忆 → 提示阶梯反馈 → 错误分类 → 变式迁移
→ 间隔重复排期 → 监考式无AI测验 → gate 通关 → 真实世界迁移
```

## 核心理念

> AI 缩短反馈循环;它不是知识源。能力 = 撤掉 AI 之后你还能做什么。

传统 AI 辅导最大的问题:**fluency 错觉**——AI 带着做,什么都会;AI 撤走,什么都不会。这个 skill 的一切设计都在对抗这件事:基线诊断测真实起点、监考式测验测真实掌握、gate 关卡卡住进度,效率模式也豁免不了。

## 两层设计

**日常辅导(默认,轻量)**:只守三条铁律,不建任何文件——① 尝试先于答案 ② 每次会话至少 1 次主动回忆 ③ 错一次记一个错误类型。轻,才用得起来。

**系统学习(说"系统学 X"/"做套课程"时启用)**:完整闭环,全套机制:
- 知识地图 map.md(地形 + 进度)→ 间隔重复排期 review-queue.md(3-7-14 天)→ 监考式无AI测验(题目答案分离、一题一问当场判分)→ gate 通关(所有模式强制)→ 真实迁移收官
- 触发词边界清晰,agent 不用猜:「系统学 X/做套课程/学习计划」进系统层;「这是什么/帮我看看/为什么报错」留日常层

## 安装

```bash
npx skills add 9Ashwin/tutor-skills --skill socratic-tutor
```

或者把 `skills/socratic-tutor/` 目录复制进你的 agent 技能目录。

## 核心机制

| 机制 | 解决什么 | 怎么落地 |
|------|----------|----------|
| 提示阶梯 | 直接给答案 = 学习者不动脑 | 五级:尝试→错误区域→引导问题→给原则→局部示例→(仅应求)完整解法 |
| 主动回忆 | fluency 错觉 | 讲解前先让学习者凭记忆默写/口述 |
| 错误类型映射 | 泛泛"你错了"没指导 | 概念缺失→重教、条件遗漏→边界变式、错误类比→反例、计算→专项、策略→专家思路、粗心→检查清单 |
| 监考式无AI测验 | 开卷自测 ≠ 真实掌握 | questions.md 与答案分离、一题一问当场判分、有AI轮用同难度不同题 |
| gate 关卡 | 进度不被效率模式绕过 | 无AI ≥90% + 迁移独立完成 + 解释原理 Rubric A、B 均≥3;任何模式都豁免不了 |
| 间隔重复排期 | 存储强度(长期保持) | review-queue.md 记 3-7-14 天,会话开场先清到期项 |
| Rubric 批改 | 开放答案凭感觉打分 | A 概念正确/B 推理链/C 证据/D 未支持假设,0-4 |
